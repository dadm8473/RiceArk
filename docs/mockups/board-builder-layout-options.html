작은 스프레드시트/보드 빌더 레이아웃 비교

넓은 화면에서도 표 자체는 내용 크기만큼 유지하고, 남는 공간은 작업 영역으로 쓰는 방향입니다. 아래 세 가지 중 B안은 여러 표를 한 화면에 배치하기 좋고, A안은 가장 단순합니다.

최종 방향 메모

아래 비교 목업의 표는 구조 설명을 위한 표현입니다. 최종 UI는 모든 셀을 선으로 둘러싸는 표가 아니라, 작은 체크박스 상자를 픽셀 단위 행/열 위에 배치하는 방식으로 봅니다.

  • 열 너비와 행 높이는 사용자가 픽셀 단위로 조절
  • 숙제 축 구분선은 기본 제공
  • 캐릭터 축 구분선은 사용자가 필요한 곳에 추가
  • 숙제별 색상이 체크박스 색상으로 반영
  • 배치/색/구분선은 완료 데이터와 분리 저장
