# 벨가 숙제 프리셋 설계

## 목표

숙제 추가 화면의 기존 로스트아크 프리셋에 `벨가` 주간 숙제를 추가한다.

## 프리셋 정의

- ID: `velgardin`
- 표시명: `벨가`
- 상세명: `죽음의 계율자, 벨가르딘`
- 초기화 주기: `weekly`
- 색상: `#1d4ed8`
- 표시 위치: `세르카` 다음, `성당` 이전

## 구현 범위

기존 `LOST_ARK_TASK_PRESETS` 배열에 항목을 추가한다. 프리셋을 선택하면 기존 동작대로 숙제 이름, 초기화 주기, 색상이 입력 폼에 반영된다. 서버 API와 데이터베이스 형식은 변경하지 않는다.

## 검증

`TaskForm` 테스트에서 프리셋 데이터의 순서와 값, 화면 상세명, `벨가 숙제 프리셋 적용` 접근성 이름을 검증한다. 이후 웹 타입 검사와 전체 테스트, 프로덕션 빌드를 실행한다.
