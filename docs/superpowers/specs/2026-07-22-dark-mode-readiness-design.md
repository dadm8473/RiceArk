# Dark Mode Readiness Design

## Goal

RiceArk의 다크모드가 보드, 공통 모달, 설정 폼, 도구 패널, 포털 UI에서 일관된 표면과 읽을 수 있는 텍스트 대비를 제공하도록 정비한다.

## Scope

- `html`, `body`, 앱 셸이 같은 테마 배경과 `color-scheme`을 사용한다.
- 저장된 테마를 React 실행 전에 적용해 초기 라이트 화면 노출을 줄인다.
- 브라우저 저장소 접근이 제한되어도 앱은 라이트 테마로 안전하게 시작하고 테마 전환을 계속 제공한다.
- 저장·삭제 버튼의 의미 색상과 모바일 브라우저 테마 색상을 현재 테마에 맞게 유지한다.
- 공통 모달 헤더, 편집 폼, 읽기 전용 값, 탭 설정, 도구 패널과 캐릭터 검색 결과에 다크 표면을 적용한다.
- 보드 캐릭터 메타데이터, 일정 제목과 보조 정보, 일정 배지 및 섬 정보를 다크 배경에서 읽을 수 있게 한다.
- `document.body`에 포털로 렌더링되는 메모 툴팁과 드래그 오버레이에도 다크 스타일을 적용한다.
- 비활성 체크칸이 밝은 사각형으로 보이지 않게 한다.

## Approach

`:root`와 `:root[data-theme="dark"]`에 배경, 표면, 텍스트, 테두리용 의미 토큰을 정의한다. 기존 라이트 디자인은 유지하고, 공통 컴포넌트의 다크 규칙은 토큰을 사용해 한곳에서 관리한다. 사용자 지정 메모 색상과 상태별 강조색은 유지하되 주변 표면과 일반 텍스트만 다크 테마에 맞춘다.

## Verification

- CSS 회귀 테스트에서 루트 테마, 공통 컴포넌트, 보드 정보, 포털 선택자를 확인한다.
- 전체 타입 검사와 테스트를 실행한다.
- 운영과 동일한 앱을 데스크톱 및 모바일 뷰포트에서 확인하고 콘솔 오류와 가로 넘침을 점검한다.
